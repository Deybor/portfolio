# Confluence and Iced-out ring technical packs

Eight controlled sheets per ring: specification overview; saved assembly dimensions; true metal section and exploded stone identification; materials/finish/BOM; manufacturing and proposed tolerances; sample QC; costing/MOQ inquiry; source control and release gates.

New packs are linked from each existing gallery. The earlier dimension drawings remain available as separate documents. Amara and the approved galleries are preserved.

`render-ring-specifications.py` reads the actual frozen Blender scenes in a separate process, creates isolated temporary rendering scenes, and never saves a Blender source. Camera matrices and measured envelopes are recorded. `build-ring-specifications.py` uses these measurements for vector annotations and real triangle-plane section contours. Source SHA-256 is verified at build time. Both models are unchanged.

Confluence now uses the user-requested, separately saved stone-free straight-prong CAD revision. The original prong-free audit frame is preserved in a copy and exact Boolean unions add twelve straight Z-axis stock cylinders (centre diameter 0.95, side diameter 0.80). A numerical three-edge Boolean hole is closed and coincident vertices are merged at 0.000001 mm before the saved-copy audit. Beauty renders remain the approved original design. Wireframe and new dimensions both use the exact new CAD body. Existing supplied casting STL is a different prong geometry and is not silently superseded. The original source blend is unchanged. The supplied solid-18K route is retained as an original alternative; silver/plating/moissanite is explicitly a quoting proposal.

Iced-out uses the original retained CAD object, `CAD base - exact source mesh`, as explicitly requested. The modified beauty metal and all added stones are excluded from the specification. Original body dimensions: 22.018 x 4.138 x 22.018 in source X/Y/Z, interpreted as mm pending author confirmation. The ring axis is Y. New original-only bore sampling gives 17.22854 minimum clear diameter. No separate stones exist in this scene: purchased-stone quantities, sizes and row allocation stay TBC. Existing split coincident vertices give raw topology boundaries; an analysis-only weld at 0.00001 removes boundary/nonmanifold edges. This is not a changed original master or casting certification.

Materials proposal: 925 silver / 18K yellow gold electroplate / 3.5-micron target / round brilliant moissanite. These values are proposed for compatibility with the user's supplied job brief, not approved ITURA specifications or purchased-stone data. Alloy, coating stack and limits, actual stones, final tolerances, cost, MOQ, manufacturing sample, supplier and production release remain explicit open fields. Quote tiers 50/100/250 are inquiry quantities only. No quotes, commissions, production, or affiliation are claimed.

Technical references consulted 02 October 2026: GIA Bench Tip 17 for contour-matched bearings and rounded prongs; Formlabs jewellery design parameters for pattern/process review; ASTM B568's description of X-ray coating-thickness measurement. The documents do not claim those resources certify the rings.
